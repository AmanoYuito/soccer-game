# サッカーやろうぜ！

同じフォルダにある Word 仕様書を参考にした、PC ブラウザ向けのプレイ可能な初期版です。監督として選手、戦術、練習、補強、施設を管理し、22 人が動く試合を観戦しながら 12 クラブ・22 節のリーグを進められます。試合では選手の位置とボールを 30Hz の固定ステップで計算し、パス・ドリブル・シュート・セーブ・得点を処理します。試合中の戦術変更、最大 5 人・3 回の交代機会、ハーフタイム交代に対応します。データは IndexedDB に自動保存でき、JSON の書き出し・読み込みにも対応します。

試合画面はオリジナルのドット絵で、スコア・ピッチ・実況・監督操作をまとめています。標準ではボールを大きく追う斜め視点で、ピッチを対角から映します。画面上で斜め・追従・全体の3視点を切り替えられ、拡大視点では小さな全体図で位置関係も確認できます。
ゴールにはポストと奥行きのある網目を描き、得点時はネットが揺れます。ボールは白黒のパネル、回転、地面の影、飛行時の軌跡を描きます。
ゴール後は直前の約7秒を自動リプレイし、得点者とスコアを表示します。「試合へ戻る」でスキップできます。ホーム画面はクラブ施設を歩くように選べるクラブマップです。編成・戦術・育成・移籍などの施設を絵の上に配置し、試合もスタジアムから始められます。各施設の画面では、選手たちが動く練習場を背景に表示します。スマートフォンでは施設を押しやすい2列のメニューに並べ替えます。
試合の前には対戦相手の順位・戦績・攻守の目安・注目選手・予想先発11人を確認できます。画面で見た相手の11人がそのまま試合に登場します。ここから編成や戦術を確認してからキックオフできます。
リプレイには得点者と、直前のパスから得点した場合のアシスト選手を顔つきで表示します。選手の顔は眉・目・表情の違いを増やしました。試合中の交代は監督席でピッチ上の選手と控えを順に選ぶだけで予約できます。ハーフタイムはその場で交代します。
編成画面ではピッチ上の位置を選び、候補選手の「起用」で先発と控えを入れ替えられます。布陣の切り替え、位置適性と体力の確認も同じ画面でできます。育成画面は選手を選んで練習メニューを指定する形式です。試合画面はピッチを大きく表示し、監督席のタブでベンチ・試合情報・記録を切り替えます。これらの画面は明るい携帯ゲーム風の配色で、素材と画面構成はオリジナルです。
育成画面では、選択した選手の総合・シュート・パス・守備・スピードをS〜Gランクと数値で横並びに表示し、左の選手一覧でも総合ランクを比較できます。
試合中の基本操作は一時停止、速度変更、監督メニューの3つです。選手の体力と試合記録は必要なときに開けます。選手一覧、プロフィール、移籍市場には選手ごとに異なるオリジナルの顔アイコンを表示します。
試合ではドリブル、パス、シュート、タックル、スライディング、ジャンプしてのヘディング、GKのキャッチとパンチングを姿勢とボールの動きで表現します。ピッチ上にプレー名のラベルは出しません。守備側は寄せとマークを分担し、攻撃側はパスコースを作って受け手が動きます。練習は育成画面で選手ごとに選択でき、試合終了時と育成画面にはシュート精度・ヘディングなど実際に上がった細かい能力を表示します。上昇前の成長ポイントも能力名と％で確認できます。出場・年齢・素質・練習施設に応じてポイントがたまり、複数試合かけて能力が伸びます。
守備選手と対峙すると、ドリブル・敏捷性・ボールコントロールと守備能力からフェイントや股抜きを判定します。成功時は相手が一瞬体勢を崩し、選手の切り返しやボールの通り道で突破を表現します。試合情報で突破回数を確認できます。
選手の動きは、ボールの位置に合わせて守備・中盤・前線を連動させる配置に更新しました。守備は一人が相手をゴール側から寄せて減速し、もう一人が後方のパスコースをカバーします。残りの選手は持ち場を保ちながら近くの相手をマークします。攻撃時は二人が斜め前後にサポートし、最終ラインはボールの後ろに残ります。味方同士が同じ場所に重ならないよう移動も調整しています。

選手は髪型・髪色・肌色・体格・アクセサリーを個別に変更でき、顔写真風のドット絵と試合中の姿に反映されます。能力は仕様書に合わせて1〜100の数値とS〜Gの8段階で表示します。選手詳細では技術・守備・身体・判断、GKには専用能力を表示します。身長・体重・利き足・成長タイプも個別に設定され、成長タイプは試合後の経験値に影響します。古いセーブは読み込み時に新しい項目を補います。

`dist/index.html` をブラウザで開くか、`soccer-game` ディレクトリで `python3 -m http.server 8000 -d dist` を実行して `http://localhost:8000` を開いてください。

試合エンジンの確認は `node tests/match-engine.test.js` で実行できます。固定ステップの再現性、22 人の位置、試合終了、交代の制約を確認します。
個人練習の効果は `node tests/training.test.js` で確認できます。
能力評価とセーブ移行は `node tests/player-data.test.js` で確認できます。

この版は仕様書全体の完成版ではありません。描画は軽量な Canvas 実装で、オフサイド、ファウル、カップ戦、海外リーグなどはまだありません。試合中の状態は保存されず、再読み込みすると試合前から再開します。
選手は特殊能力を最大5つまで習得できます。スーパーサブは後半の途中出場で能力が上がり、ワンタッチパス、ミドルシューター、空中戦の達人、ドリブル突破、鉄人、守護神もそれぞれ試合中のプレーに影響します。能力にはLv.1〜3があり、選手詳細と監督席で確認できます。育成画面で選手ごとに習得目標を選ぶと、各試合後に練習と出場経験で進捗がたまり、必要値に達すると新規習得またはレベルアップします。対応する練習メニューと練習施設の強化で進捗が速くなります。既存のセーブにも初期能力を付与します。仕様書の「FK職人」など、対応する試合処理のない特性は今後の対象です。
