# サッカーやろうぜ！

同じフォルダにある Word 仕様書を参考にした、PC ブラウザ向けのプレイ可能な初期版です。監督として選手、戦術、練習、補強、施設を管理し、22 人が動く試合を観戦しながら 12 クラブ・22 節のリーグを進められます。データは IndexedDB に自動保存でき、JSON の書き出し・読み込みにも対応します。

`dist/index.html` をブラウザで開くか、`soccer-game` ディレクトリで `python3 -m http.server 8000 -d dist` を実行して `http://localhost:8000` を開いてください。

この版は仕様書全体の完成版ではありません。試合の描画とイベント計算は軽量な独自実装で、オフサイド、ファウル、カップ戦、海外リーグなどはまだありません。
